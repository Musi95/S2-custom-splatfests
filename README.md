## Installation

Download the version for your region (USA, EUR, or JPN). Drag the `atmosphere` folder onto the root of your SD card. That's it.

## Contents

Each Splatfest includes:
- `System/GameConfigSetting.xml`
- `DebugUnderPilot/bcat/fesdata/` (festival textures and stage data)
- `DebugUnderPilot/bcat/vsdata/` (Versus mode settings)
- `DebugUnderPilot/bcat/coopdata/` (Co-op settings)
